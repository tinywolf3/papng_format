# PAPNG 1.0 샘플

[한국어 기준 명세](../spec/PAPNG-1.0.ko.md)의 기능을 [웹 뷰어](../demos/web/viewer/README.md)에서 살펴볼 수 있는 리소스입니다. 파일은 실제 RGBA8 APNG이며 확장 정보는 `paEX`와 선택적 `iTXt` 청크에 들어 있습니다. 메타데이터용 마지막 프레임은 없습니다.

## 샘플에서 확인할 내용

- **[팔레트 정원](palette-creature.papng)** — 24×24, 8프레임. 몸체·꽃·반짝임의 H16을 바꾸면서 픽셀별 명암이 유지되는지 확인합니다. 마스크 4개 중 하나는 반투명입니다. 출력 크기, 바운딩 박스, 픽셀 배수, 피벗, 클립, 마스크 그룹을 모두 포함합니다. `blink` 클립은 2–4번 프레임을 3번 재생합니다.
- **[확률의 박자](distribution-beats.papng)** — 24×24, 6프레임. `FIXED_DELAY`와 `RANDOM_DELAY`, 다섯 분포 종류를 사용합니다. 0번 프레임의 고정 시간은 50/0 → 50/100초입니다. 나머지는 균등·삼각·작은 값 선호·큰 값 선호·숫자 배열 분포로 지연을 선택합니다. 숫자 배열은 150·400·900ms에 상대 가중치 1·3·1을 줍니다. 뷰어의 지연 표시와 프레임 번호를 관찰하세요.
- **[점프 궤도](jump-orbit.papng)** — 24×24, 8프레임. `RELATIVE_JUMP`, `ABSOLUTE_MOVE`, `RANDOM_RELATIVE_JUMP`, `RANDOM_ABSOLUTE_MOVE`를 모두 포함합니다. 기본 APNG 지연은 400ms입니다. 0 → 2 → 4로 이동한 뒤, 4번에서 -2·0·+1 중 하나를 가중치 2·1·5로 선택합니다. 5번에서는 전체 프레임 중 균등하게 이동합니다. 역방향·자기 자신으로 이동할 때도 합성 결과가 유지됩니다.
- **[보이지 않는 준비](hidden-growth.papng)** — 16×16, 5프레임. 0–2번 프레임은 시간이 0이며 땅·줄기·잎을 합성만 합니다. 처음 출력되는 3번에는 그 결과와 꽃이 함께 보입니다. 부분 프레임, `SOURCE`·`OVER`, `BACKGROUND`, 유한 반복 3회를 확인할 수 있습니다.
- **[유리와 잔상](restore-previous.papng)** — 16×16, 3프레임. 반투명 `OVER` 프레임을 `PREVIOUS`로 폐기하고 뒤로 점프합니다. 앞의 유리 흔적이 누적되지 않아야 합니다. Adam7 인터레이스와 압축된 `PAPNG.Metadata`도 사용합니다.
- **[300개의 작은 순간](300-frame-spectrum.papng)** — 1×1, 300프레임. 일반 RGBA 픽셀만 사용하며 마스크와 추가 분포 개수가 0입니다. 내장 균등분포는 여전히 존재합니다. 최소 32×32 및 최대 256프레임 제한이 없음을 보여줍니다. 0–299번 프레임을 10ms씩 한 번 재생합니다.

이 여섯 파일은 v1의 제어 타입 0–5, 분포 종류 0–4, 네 표시 힌트, 클립과 마스크 그룹을 모두 포함합니다. 랜덤 샘플의 실제 재생 순서는 매번 달라질 수 있습니다. 일반 APNG 뷰어에서는 읽을 수 있지만 마스크 색상이나 확장 재생 동작은 복원되지 않습니다.

## 재생성

저장소 루트에서 의존성을 설치한 후 실행합니다.

```sh
npm run samples
```

[생성기](../tools/generate-samples.ts)는 좌표와 색상을 코드로 정의한 작은 픽셀아트를 작성합니다. 외부 이미지가 필요하지 않습니다. 같은 실행 환경에서 파일 내용이 결정적으로 재생성되며, 바이너리 파일과 `manifest.json`은 공유할 수 있도록 소스와 함께 관리합니다. 압축 라이브러리 버전이 바뀌면 PNG 데이터의 압축 바이트는 달라질 수 있습니다.

이 디렉터리에는 정상 파일을 둡니다. 잘못된 CRC·인덱스·분포·메타데이터, 포스터 분리, 모든 PNG 필터, 취소 가능한 0시간 순환 등은 [자동 테스트](../tests/core.test.ts)에서 별도 파일을 구성하여 검증합니다.
