# PAPNG 1.0 샘플

[한국어 기준 명세](../spec/PAPNG-1.0.ko.md)의 기능을 [웹 뷰어](../demos/web/viewer/README.md)에서 살펴볼 수 있는 리소스입니다. 파일은 실제 RGBA8 APNG이며 확장 정보는 `paEX`, 선택적 `paMD`와 `iTXt` 청크에 들어 있습니다.

## 샘플에서 확인할 내용

- **[팔레트 정원](palette-creature.papng)** — 24×24, 8프레임. 몸체·꽃·반짝임의 색상각 변화량(ΔH)을 바꾸면서 원본 명암과 픽셀별 알파가 유지되는지 확인합니다. 마스크 4개 중 하나에는 반투명 픽셀이 있습니다. 출력 크기, 바운딩 박스, 픽셀 배수, 피벗, 클립, 마스크 그룹을 모두 포함합니다. `blink` 클립은 2–4번 프레임을 3번 재생합니다.
- **[확률의 박자](distribution-beats.papng)** — 24×24, 6프레임. `FIXED_DELAY`와 `RANDOM_DELAY`, 다섯 분포 종류를 사용합니다. 0번 프레임의 고정 시간은 50/0 → 50/100초입니다. 나머지는 균등·삼각·작은 값 선호·큰 값 선호·숫자 배열 분포로 지연을 선택합니다. 숫자 배열은 150·400·900ms에 상대 가중치 1·3·1을 줍니다. 뷰어의 지연 표시와 프레임 번호를 관찰하세요.
- **[점프 궤도](jump-orbit.papng)** — 24×24, 8프레임. `RELATIVE_JUMP`, `ABSOLUTE_MOVE`, `RANDOM_RELATIVE_JUMP`, `RANDOM_ABSOLUTE_MOVE`를 모두 포함합니다. 기본 APNG 지연은 400ms입니다. 0 → 2 → 4로 이동한 뒤, 4번에서 -2·0·+1 중 하나를 가중치 2·1·5로 선택합니다. 5번에서는 전체 프레임 중 균등하게 이동합니다. 역방향·자기 자신으로 이동할 때도 합성 결과가 유지됩니다.
- **[보이지 않는 준비](hidden-growth.papng)** — 16×16, 5프레임. 0–2번 프레임은 시간이 0이며 땅·줄기·잎을 합성만 합니다. 처음 출력되는 3번에는 그 결과와 꽃이 함께 보입니다. 부분 프레임, `SOURCE`·`OVER`, `BACKGROUND`, 유한 반복 3회를 확인할 수 있습니다.
- **[유리와 잔상](restore-previous.papng)** — 16×16, 3프레임. 반투명 `OVER` 프레임을 `PREVIOUS`로 폐기하고 뒤로 점프합니다. 앞의 유리 흔적이 누적되지 않아야 합니다. Adam7 인터레이스와 주석이 들어 있는 압축 JSON5 `PAPNG.Metadata`도 사용합니다.
- **[300개의 작은 순간](300-frame-spectrum.papng)** — 1×1, 300프레임. 일반 RGBA 픽셀만 사용하며 마스크 슬롯과 추가 분포 개수가 0입니다. 내장 균등분포를 사용하며, 한 픽셀의 색상 변화를 300프레임에 걸쳐 표현합니다. 0–299번 프레임을 10ms씩 한 번 재생합니다.
- **[하나의 마스크, 일곱 알파](alpha-ribbons.papng)** — 28×14, 4프레임. 서로 다른 두 원본 색상과 알파 0·1·32·64·128·192·255를 마스크 0 하나로 묶습니다. ΔH는 색상각 차이를 유지하며 모든 픽셀의 알파를 그대로 둡니다. 네 프레임은 같은 압축 마스크 배열 하나를 공유합니다.

- **[소켓 친구](socket-buddy.papng)** — 48×40, 6프레임. `right_hand`와 `head` 이름을 한 번 정의하고 0·2·4번 프레임에 모든 `(x, y, r)`을 함께 기록합니다. 1·3·5번은 이전 레코드를 상속합니다. 손 소켓은 -35°로 회전한 뒤 `[x, y]`로 다시 정의하여 회전을 0으로 되돌립니다. 머리 소켓에는 12.5°도 사용합니다. `raised` 클립은 3번에서 시작하여 클립 밖 2번의 소켓 값을 상속합니다.
- **[별빛 지팡이](socket-wand.papng)** — 10×20, 4프레임. 손잡이의 `(5, 17)`을 pivot으로 지정합니다. 125ms 간격으로 반짝여 500ms 간격의 부모와 독립적으로 재생됩니다. 단독 파일로도 열 수 있습니다.

[소켓 친구의 JSON5 원문](socket-buddy-metadata.json5)에는 주석과 `developer_notes`를 포함한 개발자 참고 정보가 있습니다. 이 원문은 PAPNG의 `iTXt`에 그대로 들어가며, 웹뷰어의 **JSON5 메타데이터 보기**에서도 확인할 수 있습니다.

웹 뷰어에서 **소켓 친구**를 선택하면 지팡이를 함께 불러옵니다. 손·머리 소켓을 바꾸거나 소켓 안내선과 부속 표시를 켜고 끌 수 있습니다. 이 두 리소스의 연결은 데모의 `manifest.json`에만 설정하며 PAPNG 메타데이터에 외부 파일 경로를 저장하지 않습니다.

이 아홉 파일은 v1의 제어 타입 0–5, 분포 종류 0–4, 네 표시 힌트, 클립·마스크 그룹·소켓을 모두 포함합니다. 랜덤 샘플의 실제 재생 순서는 매번 달라질 수 있습니다. 일반 APNG 뷰어에서도 원본 색상과 픽셀별 알파가 그대로 보입니다. 실행 시 색상각 변화량과 확장 재생 제어만 적용되지 않습니다.

모든 마스크 슬롯에는 `PAPNG.Metadata.mask_groups`의 단일 인덱스 그룹으로 표시 이름을 넣었습니다. 몸체·꽃잎·강조 막대·궤도 점·반투명 유리처럼 역할을 표시하고, 실제로 사용하지 않는 슬롯에는 예비 마스크라는 이름을 사용합니다. 뷰어는 이 이름과 원본 평균색의 H를 함께 표시합니다.

## 재생성

저장소 루트에서 의존성을 설치한 후 실행합니다.

```sh
npm run samples
```

[생성기](../tools/generate-samples.ts)는 좌표와 색상을 코드로 정의한 작은 픽셀아트를 작성합니다. 외부 이미지가 필요하지 않습니다. 같은 실행 환경에서 파일 내용이 결정적으로 재생성되며, 바이너리 파일, JSON5 참고 파일과 `manifest.json`은 공유할 수 있도록 소스와 함께 관리합니다. 압축 라이브러리 버전이 바뀌면 PNG 데이터의 압축 바이트는 달라질 수 있습니다.

`paMD`는 모든 값이 0인 마스크를 생략하고, 치수와 배열이 같은 프레임은 같은 데이터를 참조합니다. 이미지의 RGBA와 마스크 배열은 각각의 청크에 저장합니다.
