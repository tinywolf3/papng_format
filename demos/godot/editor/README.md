# PAPNG Editor

Linux·Windows·Android용 Godot 4.7.2 픽셀 이미지 편집기입니다. PAPNG·APNG·PNG를 열고, 원본 RGBA와 별도 마스크를 편집한 뒤 PAPNG로 저장합니다. 포맷은 PAPNG 1.0 / 문서 개정 1을 따릅니다.

[GIMP의 도구함·이미지 창·도크 구성](https://docs.gimp.org/3.0/en/gimp-concepts-main-windows.html)을 참고했습니다. 왼쪽 도구함, 가운데 원본 프레임, 오른쪽 속성·미니맵·커서 정보, 아래 프레임 목록으로 구성합니다.

## 실행과 빌드

저장소 루트에서 실행합니다. Python 3.10 이상, Godot **4.7.2 stable**과 같은 버전의 export templates가 필요합니다. `GODOT_BIN`으로 실행 파일을 지정할 수 있습니다.

```sh
# 소스 실행
GODOT_BIN=/path/to/godot
"$GODOT_BIN" --path demos/godot/editor

# Linux/Windows 실행 파일 생성
python3 tools/editor/build.py linux windows --templates /path/to/templates
```

템플릿은 압축을 푼 `templates` 디렉터리 또는 공식 `Godot_v4.7.2-stable_export_templates.tpz` 파일을 지정합니다. 뷰어 빌드에서 이미 준비했다면 `--templates`는 생략할 수 있습니다.

출력은 `builds/linux/papng-editor/`와 `builds/windows/papng-editor/`에 생성됩니다. Linux는 `papng-editor.x86_64`, Windows는 `papng-editor.exe`를 실행합니다. 같은 폴더의 압축 파일은 실행 파일과 라이선스를 포함한 휴대용 배포본입니다. 파일 선택기 또는 창에 파일을 끌어 놓아 열 수 있고, 실행 인수로 PAPNG/APNG/PNG 경로를 전달할 수도 있습니다.

```sh
./builds/linux/papng-editor/papng-editor.x86_64 -- samples/palette-creature.papng
```

Android 빌드에는 Android SDK (platform 36, build-tools 36.1.0), JDK 21과 Gradle의 의존성 다운로드 환경이 필요합니다. `ANDROID_HOME`과 `JAVA_HOME`을 설정하고 다음 명령을 실행합니다.

```sh
python3 tools/editor/build.py android --templates /path/to/templates
```

`builds/android/papng-editor/papng-editor-debug.apk`를 생성하며 arm64 기기와 x86_64 에뮬레이터를 지원합니다. 로컬 디버그 키로 서명한 설치용 APK입니다. 스토어 배포에는 별도의 배포 서명 설정이 필요합니다. 기존 뷰어와 함께 설치할 수 있습니다.

## Android 터치 편집기

Android에서는 같은 문서·재생·저장 코어에 별도의 터치 화면을 사용합니다. 소스는 `mobile/`에 모았습니다. [Pixel Studio의 공개 Android UI](https://play.google.com/store/apps/details?id=com.PixelStudio)에서 큰 작업 영역, 아이콘 도구 모음, 제스처 확대·이동을 참고했습니다. 아이콘은 이 프로젝트에서 직접 작성했습니다.

- 하단 도구 모음은 가로로 넘길 수 있습니다. 아이콘과 키보드 단축키를 표시하며 길게 누르면 이름 툴팁이 표시됩니다. 색상칩으로 RGBA, 옆 입력으로 브러시 크기를 정합니다.
- 한 손가락으로 그리거나 사각 선택합니다. 두 손가락은 정수 배율 확대·축소와 이동입니다. 두 번째 손가락이 닿으면 진행 중인 선을 취소해 확대 동작으로 생긴 흔적을 막습니다. 이동 도구를 켜면 한 손가락으로도 화면을 옮깁니다.
- 상단에 1:1 미니맵과 마지막으로 터치한 픽셀의 좌표·RGBA·HSV·마스크 번호를 표시합니다. 프레임 목록은 필름 아이콘으로 접을 수 있습니다.
- 메뉴에서 파일 열기·새 이미지·저장·PNG 내보내기, 복사·잘라내기·붙여넣기, 프레임 추가·복제·삭제·순서 변경을 합니다. 가져오기는 오려내기와 픽셀화 두 단계이며 출력 크기·보간·색 단계를 선택합니다. 편집 화면에서 위치를 정하고 **✓ 적용**을 누릅니다.
- **속성**에는 데스크톱과 같은 프레임 제어·분포, 마스크·이름·그룹, 소켓·부속 미리보기, 출력 힌트·피벗, 클립과 JSON5 메타데이터 편집이 있습니다. **보기**에는 격자·십자선·마스크 강조·힌트·소켓·어니언과 마스크 해제 브러시가 있습니다.
- 공유 분포는 종류 선택과 가중치 숫자 입력 폼으로 편집합니다. 마스크 그룹과 자유 메타데이터는 JSON5 편집 창을 사용합니다.
- 저장되지 않은 작업의 복구 사본을 약 30초마다 백그라운드로 작성하며 다음 실행에서 복구할 수 있습니다. 앱 강제 종료 직전의 변경까지 보장하지는 않으므로 작업 파일은 저장 버튼으로 보관하세요.
- Android 시스템 파일 선택기로 문서를 열고 저장합니다. 다른 앱의 **연결 프로그램 / 공유**에서도 열 수 있습니다. 전체 저장소 접근 권한이나 인터넷 권한을 요구하지 않습니다.
- PAPNG·APNG·PNG 열기는 원본 프레임과 확장 정보를 편집합니다. 이미지 가져오기는 Godot 기본 형식에 더해 Android 플랫폼이 지원하는 GIF 첫 이미지·HEIF·AVIF 등을 사용합니다. 기기·Android 버전에 따라 디코더 지원이 달라집니다. 데스크톱 ImageMagick 전용 형식(TIFF·PSD·RAW 등)은 Android에서 지원하지 않으며 PNG 등으로 변환해야 합니다.
- Android 문서 제공자는 임시 파일 교체를 지원하지 않을 수 있습니다. 먼저 앱 내부에서 PAPNG를 검증하고 사본을 만든 뒤 선택 문서에 기록하고 다시 읽어 확인합니다. 쓰기 실패 시 앱 내부 사본을 유지하므로 다른 위치로 다시 저장할 수 있습니다. 외부 문서의 원자적 교체는 보장하지 않습니다.

데스크톱에서 `-- --mobile` 실행 인수를 주면 터치 화면을 미리 확인할 수 있습니다. Android 편집기에는 데스크톱용 OS 파일 연결 설치기는 포함하지 않습니다. 기존 이미지 뷰어는 별도 앱으로 유지됩니다.

## 픽셀 작업

- 도구함은 아이콘과 단축키 라벨을 모아 표시하고 전체 이름은 툴팁으로 제공합니다. 도구 창의 폭을 바꾸면 편집 도구와 선택 작업 버튼이 자동으로 줄을 바꿔 배치됩니다.
- 연필·지우개·연결 영역 채우기·스포이트·직선·사각형·사각 선택을 지원합니다. 브러시 크기와 RGBA 색상을 지정할 수 있습니다.
- 마우스 휠은 **1~128의 정수 배율**입니다. `1`은 실제 크기, `F`는 화면에 맞는 정수 배율입니다. 실제 크기보다 축소하지 않으며, 큰 이미지는 가운데 버튼 또는 Space+드래그로 이동합니다.
- 오른쪽 미니맵은 **1 이미지 픽셀 = 1 UI 픽셀**로 합성 결과를 표시합니다. 큰 이미지는 미니맵의 스크롤바로 탐색합니다. HiDPI 데스크톱에서는 OS의 화면 배율이 별도로 적용됩니다.
- 커서 도구창에 캔버스 좌표·원본 RGBA8·HSV·마스크 번호가 계속 표시됩니다. 십자선은 해당 픽셀의 중앙을 지납니다.
- `Ctrl+C/X/V`는 앱 내부 클립보드입니다. RGBA와 마스크를 함께 복사합니다. 붙일 위치를 드래그로 정하고 Enter로 적용하며 Esc로 취소합니다. 기본은 알파 합성이고, **투명 픽셀도 교체**를 켜면 투명 픽셀까지 SOURCE로 덮어씁니다.
- `Ctrl+Shift+V`는 OS 클립보드의 이미지를 가져오기 창으로 엽니다. Godot의 시스템 이미지 쓰기 API가 없어 앱에서 복사한 픽셀을 다른 앱의 이미지 클립보드로 내보내지는 않습니다. 외부 공유에는 PNG 내보내기를 사용합니다.
- `Ctrl+Z/Y`로 실행 취소·다시 실행합니다. 이력은 최대 32작업 / 약 128 MiB이며, 마지막 한 작업은 유지합니다.

가운데 캔버스는 **현재 APNG 원본 프레임의 영역**을 편집합니다. 이전 프레임과 합성한 결과는 미니맵과 재생에서 확인합니다. 어니언 스킨은 이전 합성 결과를 옅게 보여줍니다. 부분 프레임은 테두리로 구분하며, 영역 밖에 그리려면 프레임 탭에서 영역 크기·위치를 바꿉니다. 크기 변경은 기존 원본 영역의 왼쪽 위를 기준으로 자르거나 투명 영역을 추가합니다.

## 편집 배경과 참고 이미지

데스크톱 왼쪽 도구함의 **배경 설정**, Android의 **보기 → 편집 배경**에서 조절합니다. 기본 바탕은 투명 영역을 확인하는 **체크무늬**이며, **단색**을 선택해 원하는 색으로 바꿀 수 있습니다.

**이미지…**로 외부 이미지를 바탕 위에 놓고 그 위에서 픽셀을 그릴 수 있습니다. 이미지 가져오기와 같은 디코더·지원 형식을 사용하며 애니메이션은 첫 이미지를 참고합니다. 처음 불러오면 비율을 유지해 캔버스에 맞춥니다.

- **X/Y**: 캔버스 왼쪽 위를 기준으로 참고 이미지 왼쪽 위의 위치입니다. 음수·소수 좌표도 사용할 수 있습니다.
- **배율**: 참고 이미지의 가로세로 비율을 유지합니다. 100%는 원본 이미지 1픽셀을 캔버스 1픽셀에 대응시킵니다. **맞춤**으로 가운데 배치하거나 **100%**로 원본 배율을 복원합니다.
- **불투명도**: 0~100%로 조절합니다. 이미지 자체의 알파와 함께 적용됩니다. **이미지 표시**를 끄면 설정을 유지한 채 잠시 숨기고, **제거**는 이미지를 해제합니다.

참고 이미지는 화면 확대·축소와 이동을 따라가며 같은 캔버스 좌표에 머뭅니다. 전체 애니메이션에서 공통으로 사용하고 캔버스 밖은 표시하지 않습니다. 원본 픽셀·마스크·실행 취소 이력에 영향을 주지 않으며 미니맵·저장·PNG 내보내기에는 포함하지 않습니다. 현재 편집 세션의 참고 자료이므로 새 파일을 만들거나 다른 파일을 열거나 앱을 다시 실행하면 이미지를 다시 불러와야 합니다.

## 이미지 가져오기

**이미지 가져오기**(`Ctrl+I`)에서 파일을 선택하고, 확대·이동하며 사각형을 오려냅니다. 출력 픽셀 수, 비율 유지, 최근접/선형/Lanczos 보간, 채널별 색 단계를 선택한 다음 **선택 영역 복사 → 편집기**로 붙여넣기를 준비합니다. 원본 파일은 수정하지 않습니다.

- Godot 기본 디코더: PNG, JPEG, WebP, BMP, TGA, SVG, EXR, HDR, DDS, KTX. 실제 지원은 설치된 엔진/템플릿에 포함된 디코더를 따릅니다.
- 선택 사항인 **ImageMagick 7**: GIF, TIFF, PSD/PSB, AVIF/HEIC, JPEG XL, ICO, XCF, ORA, JPEG 2000, PCX, PNM 계열, QOI와 여러 RAW 확장자. 설치된 ImageMagick의 delegate 지원에 따라 읽을 수 있는 형식이 달라집니다.
- Linux는 배포판의 ImageMagick 7 패키지, Windows는 공식 ImageMagick 7 배포판을 설치합니다. `magick`/`magick.exe`가 PATH에 없으면 편집기 **설정**에서 실행 파일의 전체 경로를 지정합니다. 프로그램이 변환기를 자동 설치하지 않습니다.
- GIF 같은 다중 이미지의 **첫 이미지**, PSD의 첫 합성 이미지를 가져옵니다. 레이어·페이지·애니메이션 전체를 이 경로로 변환하지 않습니다. PAPNG/APNG 애니메이션은 **열기**를 사용합니다.
- 기본 가져오기는 32메가픽셀, 변환기는 최대 4096×4096, 픽셀화 출력은 최대 2048×2048로 제한합니다. 변환에는 메모리·디스크 예산과 60초 시간 제한이 있으며 취소할 수 있습니다. 이는 편집기 작업 예산이며 포맷 제한이 아닙니다.

## 프레임과 확장 기능

- 프레임 추가·이미지 복제·삭제·순서 이동, 지연 분자/분모, SOURCE/OVER와 NONE/BACKGROUND/PREVIOUS를 편집합니다. 프레임 번호는 0부터 시작합니다. 전체 목록이 클 때는 선택 프레임 주변 25개를 표시하고 번호 입력으로 이동합니다.
- **이미지 복제**는 원본 픽셀·마스크·지연·합성 속성을 복사하며 확장 제어는 비웁니다. 이동 대상을 의도하지 않게 복제하지 않도록 명시적으로 설정합니다.
- 고정/랜덤 지연, 상대/절대 이동, 랜덤 상대/절대 이동 등 6종류의 제어를 지원합니다. 0 지연 프레임은 합성에만 사용하고 출력하지 않습니다. 일반 APNG의 0 지연은 리더의 기본값으로 정규화합니다.
- 공유 분포 편집 창은 JSON5 배열을 사용합니다. 0번 균등분포는 고정이며 추가 배열의 첫 항목이 1번입니다. 종류 0~4와 가중치 값 배열을 편집할 수 있습니다.
- 마스크 브러시·선택 영역 지정/해제, 마스크 추가·이름·그룹을 지원합니다. 색상각 슬라이더와 원본/변경 색상칩은 **미리보기 설정**입니다. 색상칩은 현재 원본 프레임에서 해당 마스크의 알파 가중 평균 RGB를 표시합니다. RGBA·픽셀별 알파와 마스크 배열은 별도로 저장됩니다.
- 소켓 정의·이름·위치·회전을 편집합니다. 캔버스에서 K 도구로 위치를 정하면 픽셀 중앙 좌표를 사용합니다. 생략된 프레임은 이전 위치를 상속하고, 0번 위치는 유지합니다. 부속 PAPNG의 pivot을 선택 소켓에 연결하는 미리보기도 지원합니다. 부속 연결 설정 자체는 PAPNG에 저장하지 않습니다.
- 출력 크기·바운딩 박스·픽셀 배수·피벗 힌트, 클립의 ID·이름·프레임 구간·반복을 편집합니다. 툴바에서 격자·십자선·마스크·힌트·소켓·어니언을 켭니다.
- 순서 변경 시 점프 대상·클립·소켓 위치를 함께 조정합니다. 랜덤 대상의 확률을 그대로 표현할 수 없거나 클립이 비연속 구간으로 갈라지면 작업을 거절합니다. 참조 중인 프레임을 삭제하려면 먼저 해당 제어를 바꿉니다. 프레임의 원본 합성 순서는 새 순서를 따르므로, 부분 프레임을 재배열하면 최종 이미지가 달라질 수 있습니다.

JSON5 전체 편집으로 주석과 사용자 필드도 기록할 수 있습니다. 정상적인 메타데이터를 읽고 그대로 저장하면 텍스트를 유지합니다. 잘못된 선택 메타데이터는 경고와 함께 리더가 인정한 항목으로 복구해 편집합니다. 구조화된 도구로 특정 최상위 항목을 수정하면 그 항목의 값은 다시 직렬화하며, **그 값 내부 주석은 재작성될 수 있습니다**. 다른 항목·바깥 주석은 유지합니다.

## 저장과 작업 예산

저장기는 RGBA8 APNG, `paEX`, 중복 마스크를 공유하는 압축 `paMD`, `PAPNG.Metadata` iTXt를 생성합니다. 원본 프레임의 영역·픽셀·마스크·합성·폐기 방식과 PAPNG 확장을 유지합니다. 첫 프레임이 부분 영역이면 PNG용 기본 이미지를 별도로 만듭니다. 원본 압축 스트림·청크 순서는 다시 생성합니다. PNG의 safe-to-copy ancillary 청크와 PAPNG 이외의 iTXt는 보존합니다. 알려지지 않은 안전하지 않은 청크/향후 확장 데이터의 무손실 편집은 지원하지 않습니다.

데스크톱 저장은 구조·값을 검증하고 생성 결과를 다시 읽은 뒤 같은 디렉터리의 임시 파일을 교체합니다. 검증 실패 시 기존 파일을 덮어쓰지 않습니다. PNG/APNG 입력의 일반 **저장**은 PAPNG용 다른 이름 저장 창을 엽니다. 저장되지 않은 작업이 있으면 다른 파일 열기·새 파일·종료 전에 확인합니다.

디코딩한 전체 원본 RGBA와 마스크의 편집 예산은 256 MiB입니다. 파일 작업은 별도 스레드에서 진행합니다. 픽셀 도구·화면 합성은 CPU를 사용하므로 큰 프레임·많은 프레임은 느릴 수 있습니다. 첫 버전은 픽셀아트용 단일 문서 편집기이며 레이어, 자유 회전 선택, 전체 가져오기 애니메이션 변환은 지원하지 않습니다.
