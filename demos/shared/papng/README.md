# PAPNG desktop playback core

Unity와 Unreal 뷰어가 공유하는 C++17 구현입니다. `papng.h`의 작은 C ABI를 Unity 네이티브 플러그인과 Unreal 모듈에서 사용합니다. 각 핸들은 독립적이며, 같은 핸들의 호출은 하나의 작업 스레드에서 직렬화해야 합니다. 반환된 문자열·픽셀 포인터는 다음 상태 변경 또는 핸들 해제 전까지만 유효합니다.

- 원본 PNG 청크 CRC, APNG 프레임 번호·순서·영역과 RGBA8 PAPNG를 검증합니다.
- 일반 PNG의 팔레트·그레이스케일·16비트·인터레이스 입력을 RGBA8로 정규화합니다.
- 압축 마스크를 프레임 로컬 좌표에서 복원하고 합성 전에 HSV 변화량을 적용합니다. S/V는 가산 후 0~1로 제한하며 알파는 보존합니다.
- 합성 상태에는 PREVIOUS 복원을 위한 이전 버퍼와 마스크 강조용 합성 알파를 포함합니다.
- 캔버스 복원과 재생 방문을 분리합니다. 복원 과정에서는 랜덤 값을 뽑지 않습니다.
- 뒤로 이동할 때 캐시 또는 0번부터, 앞으로 이동할 때 순차 합성합니다. 점프 대상과 클립 시작점은 제한된 캐시에서 우선 보존합니다.
- 랜덤 지연·점프와 이산 가중 분포, 숫자 배열, 0 지연·유한 반복, 클립 경계를 처리합니다.
- JSON5 주석·후행 쉼표·식별자 키·이스케이프·숫자를 해석하고 중복 키를 거부합니다. 이름은 Unicode 식별자 범위로 검사합니다. 코드는 실행하지 않습니다.
- 잘못된 선택 확장 정보는 경고와 명세의 복구 동작으로 처리하고, 안전하게 해석할 수 없는 PNG 구조는 오류로 종료합니다.

`pp_seek`는 재생 프레임 탐색이므로 0 지연 프레임을 출력하지 않습니다. 색상 변경과 마스크 선택은 재생을 멈춘 호스트에서 수행하고 현재 클립을 처음부터 복원합니다. `pp_tick`의 방문 예산은 호출당 최대 128회·약 8ms이며, 단일 이미지 디코딩이나 캔버스 복원 시간은 이보다 길 수 있어 호스트는 작업 스레드를 사용합니다.

`pp_mask_hsv(handle, index, degrees, saturation, value)`는 ΔH(도)와 ΔS·ΔV(−1~+1 가산 차이)를 설정합니다. 기본값은 모두 0이며 변경 후 현재 클립을 재구성합니다. 기존 `pp_mask`는 H만 바꾸고 현재 S/V 설정을 유지합니다. 변화량은 파일에 저장하지 않습니다.

## 포함된 라이브러리

- stb_image: commit `f0569113c93ad095470c54bf34a17b36646bbbb5`, PNG 디코더만 사용. [upstream](https://github.com/nothings/stb), [license](third_party/stb-LICENSE.txt).
- miniz 3.0.2: 길이 제한·Adler32·압축 스트림 종료를 검증하는 tinfl 사용. [upstream](https://github.com/richgel999/miniz/tree/3.0.2), [license](third_party/miniz-LICENSE). `miniz_tinfl.inc`는 단독 inflater 헤더를 포함하도록 수정했으며 `miniz_export.h`는 정적 포함용 선언입니다.

표시용 마스크·클립·소켓 이름은 UTF-8 문자 경계를 보존하여 짧게 표시하고, 전체 이름과 메타데이터는 원본 JSON5에 유지합니다.

엔진별 빌드 진입점이 이 디렉터리를 직접 컴파일하므로 별도 라이브러리 설치나 네트워크 다운로드가 필요하지 않습니다.
