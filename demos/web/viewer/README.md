# PAPNG Pixel lab

PAPNG 1.1 리소스의 원본 RGBA·16비트 마스크 편집과 확장 재생을 확인하는 TypeScript 웹 데모입니다. [한국어 명세](../../../spec/PAPNG-1.1.ko.md)를 기준으로 구현했습니다. 라이브러리 API와 캐시 정책은 아직 실험용이며 명세의 일부가 아닙니다.

## 실행

Node.js 22.12 이상과 npm이 필요합니다. 저장소 **루트**에서 실행합니다.

```sh
npm ci
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 배포 파일과 미리보기는 다음 명령으로 준비합니다.

```sh
npm run build
npm run preview
```

배포 출력은 최상단 `builds/web/viewer/`이며, 미리보기 주소는 `http://127.0.0.1:4173`입니다. 이 출력 디렉터리를 정적 웹 서버에서 제공하면 됩니다. 상대 주소를 사용하므로 하위 경로에 배포할 수도 있습니다. Worker와 샘플 로딩을 위해 `file://`로 HTML을 직접 여는 대신 HTTP(S)를 사용하세요. 명세 문서의 HTML은 생성하지 않습니다.

## 화면 사용

- 왼쪽에서 [샘플 9개](../../../samples/README.md)를 선택하거나 로컬 파일을 열고 끌어 놓습니다. 선택한 파일은 브라우저 안에서 처리하며 서버로 업로드하지 않습니다.
- 재생·일시정지·처음부터·다음 방문 버튼과 프레임 슬라이더를 사용할 수 있습니다. 표시되는 프레임 번호는 0부터 시작합니다. 슬라이더는 해당 번호로 복원한 뒤 실제 방문을 시작합니다. 0 지연 방문은 출력하지 않으므로 곧바로 다음 출력 프레임까지 진행할 수 있습니다.
- 오른쪽에서 원본 평균색의 H를 기본값으로 표시합니다. H(0°~359.9°) 슬라이더·숫자 또는 ΔH(-180°~180°) 숫자로 HSV 변화량을 시험할 수 있습니다. ΔS·ΔV 슬라이더는 −1~+1의 가산 차이입니다. 모든 변화량이 0이면 원본색이며, 초기화하면 세 변화량이 모두 0이 됩니다. 단일 인덱스 그룹의 이름을 마스크 이름으로 표시하고 나머지 그룹 이름도 함께 보여줍니다. 마스크가 16개를 넘으면 페이지와 번호 이동을 사용합니다. 수정은 미리보기에만 적용하며 파일을 다시 저장하지 않습니다.
- 재생 중에는 팔레트 편집이 잠깁니다. 일시정지 후 변화량을 바꾸면 합성 상태와 색상에 의존하는 캐시를 폐기하고 0번부터 복원합니다. 클립이 선택되어 있으면 앞부분을 복원한 뒤 해당 클립에서 다시 시작합니다.
- 클립을 선택하면 재생 구간과 반복 횟수가 적용됩니다. 바운딩 박스·피벗은 선택적으로 겹쳐 표시하며 이미지를 자르지 않습니다. 자동 배율은 출력 크기, 픽셀 배수 순으로 참고하고 화면 안에 맞춥니다.
- 캐시 사용량, 적중 횟수, 해제 횟수, 현재 합성 상태의 크기와 복원 횟수를 표시합니다. 캐시를 끄거나 예산을 바꾸어 결과와 재사용량을 비교할 수 있습니다.

## 평균색 기준값과 마스크 이름

평균색은 웹 데모에서만 계산하는 참고값입니다. 파일이나 마스크 팔레트에 저장하지 않으며 PAPNG의 색 변환·재생 규칙을 바꾸지 않습니다. 모든 애니메이션 원본 부분 프레임에서 해당 마스크에 속한 RGB를 알파값으로 가중 평균한 뒤, 그 평균 RGB의 H를 구합니다. H 자체를 산술 평균하지 않습니다. 완전 투명 픽셀은 제외하고, 공유 마스크를 사용해도 각 프레임의 원본 RGB를 따로 포함합니다. 숨김 프레임도 포함하며 재생 시간·방문 횟수·클립·APNG 합성 결과는 가중치에 넣지 않습니다.

카드에는 원본 평균색과 그 평균색에 현재 ΔH·ΔS·ΔV를 적용한 수정색 견본을 나란히 표시합니다. H·ΔH·ΔS·ΔV 조절과 초기화에 맞춰 수정색만 갱신합니다. 수정색 견본은 기준색의 HSV 변환 미리보기이며, 변경된 전체 픽셀을 다시 평균한 색은 아닙니다. 기준 H는 0.1°로 표시합니다. H 조절값도 이 표시값을 기준으로 가장 짧은 방향의 ΔH로 환산합니다. 렌더러는 계산된 ΔH를 각 픽셀의 원본 H에 적용합니다. 따라서 모든 대상 픽셀을 한 색상각으로 통일하거나, 변경 후 픽셀 평균의 H가 조절값과 같다고 보장하는 기능은 아닙니다. 원본 평균값은 재생·이동·오프셋 수정 후에도 고정됩니다.

평균이 무채색이면 기준 H를 0°로 표시하며 H·S·V를 조절할 수 있습니다. 완전 투명한 마스크와 대상 픽셀이 없는 슬롯도 구분해 표시합니다. 완전 투명·빈 슬롯의 H 조절은 비활성화하지만 ΔH는 계속 시험할 수 있습니다. 평균색 계산은 Worker에서 진행률을 표시하며 새 파일을 열면 이전 계산을 취소합니다.

샘플의 이름은 `PAPNG.Metadata`의 `mask_groups`에서 `palette_indices: [index]`인 그룹으로 저장합니다. 같은 인덱스를 단독으로 가리키는 이름이 여럿이면 파일 순서상 첫 번째 비어 있지 않은 이름을 카드 제목으로 사용합니다. 이름이 없으면 `마스크 00`처럼 번호를 사용합니다. 이는 데모의 표시 관례입니다.

## JSON5 메타데이터와 개발자 참고 정보

`PAPNG.Metadata`는 UTF-8 JSON5로 읽습니다. `//`와 `/* ... */` 주석, 작은따옴표 문자열, 따옴표 없는 식별자 키, 후행 쉼표를 사용할 수 있습니다. `developer_notes` 같은 추가 멤버는 재생 데이터와 함께 개발자 참고 정보를 담을 수 있으며, 리더는 알 수 없는 멤버를 재생에 사용하지 않습니다. 일반 JSON으로 작성된 메타데이터도 지원합니다.

**JSON5 메타데이터 보기**를 펼치면 파일에 저장된 원문을 주석과 함께 확인할 수 있습니다. 읽기 전용이며 표시할 때 코드를 실행하거나 HTML로 해석하지 않습니다. UI에는 앞 65,536자까지 표시하고 생략 여부를 알립니다. 전체 원문은 파싱된 리소스에 보관합니다. 소켓 친구 샘플은 [JSON5 원문 파일](../../../samples/socket-buddy-metadata.json5)도 제공합니다. 유리와 잔상 샘플은 압축된 JSON5 텍스트를 사용합니다.

중복 키는 이스케이프를 해석한 뒤 검사합니다. 형식 오류나 중복 키가 있으면 선택적 메타데이터를 비활성화하고 경고합니다. 필드별 정수·범위·유한수 조건도 검사하며, `NaN`과 `Infinity`는 재생에 쓰는 수치 필드의 유효값이 아닙니다.

## 소켓과 부속 연결

**소켓 친구** 샘플에는 손과 머리 소켓이 있습니다. 기본으로 **별빛 지팡이**의 손잡이 pivot을 손 소켓에 붙입니다. 연결 지점을 바꾸면 같은 부속을 머리에도 연결할 수 있습니다. 소켓 안내선의 원은 위치, 화살표는 +x 방향을 나타냅니다. 좌표·회전각과 값을 정의한 원본 프레임 번호도 표시합니다. 안내선과 부속은 각각 숨길 수 있습니다.

소켓 이름·위치·회전은 `PAPNG.Metadata.sockets`에 저장합니다. 레코드가 없는 프레임은 번호가 가장 가까운 이전 정의를 사용합니다. 역방향 이동·랜덤 점프·클립 시작에서도 재생 이력과 무관하게 조회하며, 명시적인 `[x, y]`는 회전을 0°로 초기화합니다. 소켓은 원본 캔버스 좌표이고, 마스크의 부분 프레임 좌표와 다릅니다.

부속은 자체 Worker·Player·캐시로 복원하며 부모와 같은 시작 시각을 기준으로 각자의 지연을 소비합니다. 캐릭터는 6프레임을 500ms씩, 지팡이는 4프레임을 125ms씩 재생합니다. 재생·일시정지는 함께 적용합니다. 직접 프레임 이동·다음 방문·클립 변경·처음부터·색상 변경 시 부모는 기존 규칙대로 복원하고 부속은 첫 프레임으로 돌아갑니다. 부모의 유한 재생이 끝나면 부속도 멈춥니다. 이 동기화 정책은 데모의 선택이며 포맷 규칙이 아닙니다. 별도 Worker의 전달·화면 갱신은 프레임 단위로 완전히 동시에 일어나지는 않습니다.

Canvas는 부모 원본 캔버스 크기 안에 부모, 부속 순서로 그립니다. 부속에는 `translate(socket.x, socket.y) → rotate(socket.r) → translate(-pivot.x, -pivot.y)`를 적용하며, 스케일은 1입니다. pivot이 없으면 데모는 `(0, 0)`을 사용합니다. 캔버스 밖으로 나간 부속은 이 미리보기에서 잘립니다. 확대는 합성 후 전체에 적용하고 픽셀 보간을 끕니다. 임의 각도의 회전은 픽셀 격자에 다시 그려지므로 가장자리가 달라질 수 있습니다.

숨김 프레임은 부모·부속 각각의 합성에 사용하되 출력하지 않습니다. 부모가 마지막으로 출력한 프레임의 소켓으로 부속을 배치하며, 숨김 방문만으로 연결 위치를 바꾸지 않습니다.

자동 연결은 데모의 샘플 목록에 명시된 두 파일에만 적용합니다. 로컬 PAPNG를 열면 소켓 정보는 볼 수 있지만 문자열을 파일 경로로 해석하거나 다른 파일을 자동으로 가져오지 않습니다. 부속 로딩이 실패해도 부모의 재생과 소켓 조회는 유지됩니다. 다른 리소스로 바꾸면 기존 부속의 다운로드와 Worker를 종료합니다. 오른쪽 마스크 편집과 캐시 통계는 현재 선택한 부모 파일 기준이며, 부속의 마스크 편집은 해당 파일을 단독으로 열어 시험합니다.

## 재생 구조

UI와 Canvas 출력은 메인 스레드에서, 파일 파싱·PNG 복호화·합성·재생 상태 관리는 리소스마다 별도의 Web Worker에서 수행합니다. 압축 해제에는 브라우저의 `DecompressionStream`을 사용합니다. `json5` 라이브러리는 Worker 빌드에 포함됩니다.

```text
로컬 파일 / 샘플
  → Worker: PNG·paEX·paMD·iTXt 읽기
  → Player: 방문의 지연 평가 → 시간이 끝나면 다음 대상 선택
  → Compositor: 필요한 프레임 복원 ↔ 상태 캐시
  → 양의 지연 방문만 RGBA 버퍼 전달 → Canvas
```

PNG 필터 0–4와 Adam7을 직접 복원하여 원본 비선곱 RGBA를 얻습니다. 별도 `paMD` 청크에는 행 우선의 빅 엔디언 16비트 마스크 배열과 프레임 참조가 있습니다. 각 값의 최상위 비트가 적용 여부, 하위 15비트가 인덱스입니다. `paEX`의 `mask_count`(0–32768)가 전체 리소스의 마스크 슬롯 수를 정의합니다.

원본 부분 프레임에 대응하는 마스크를 zlib로 풀고, 각 인덱스의 ΔH·ΔS·ΔV를 원본 RGB에서 계산한 HSV에 더한 뒤 합성합니다. H는 순환하고 S/V는 각각 0~1로 제한합니다. 색 변환은 소수 정밀도로 계산하며 원본 알파를 유지합니다. 세 변화량이 모두 0이면 변환을 건너뛰므로 소스 RGBA가 바이트 단위로 동일합니다. 일반 APNG 뷰어에서도 원본 색이 정상적으로 보입니다.

동일한 배열은 한 번만 저장해 여러 프레임이 참조하고, 마스크가 없는 프레임은 참조를 생략합니다. 배열의 좌표는 `fcTL` 부분 프레임 내부 기준입니다. 마스크 인덱스를 알파 합성하거나 이전 프레임의 참조를 상속하지 않습니다.

**실제 방문과 복원을 분리합니다.** 실제 방문에서는 시간을 평가하고 필요한 난수를 한 번 추출합니다. 랜덤 이동의 추출은 지연이 끝난 후입니다. 복원 중 거치는 중간 프레임에서는 시간·난수·제어·재생 횟수 처리를 하지 않습니다.

- 앞으로 이동하면 현재 상태 또는 더 가까운 캐시 상태에서 대상까지 순서대로 합성합니다.
- 뒤로 이동하면 대상의 저장 상태를 사용하거나 0번부터의 표준 합성 결과를 재구성합니다. 캐시가 있으면 가장 가까운 앞쪽 상태부터 이어갑니다.
- 자기 자신으로 이동하면 폐기하거나 다시 합성하지 않고 새로운 방문을 시작합니다.
- 클립의 시작 전 프레임도 필요하면 이미지 복원에만 사용합니다.
- 0 지연 프레임도 폐기 연산을 포함해 정상적으로 합성합니다. 출력 이미지는 갱신하지 않습니다. 유한 재생의 마지막 방문이 숨김 프레임이어도 마지막으로 출력한 이미지가 남습니다.

시간은 분자/분모를 유지하고 분모 0을 100으로 해석합니다. 양의 시간을 정수 밀리초로 반올림하여 숨김 프레임으로 만들지 않습니다. `performance.now()`에 누적한 마감 시각을 사용하고, 한 작업에서 최대 64번의 전환 또는 약 8ms를 처리한 뒤 제어권을 양보합니다. 시간 0의 순환도 취소할 수 있으며 논리적인 지연을 임의로 넣지 않습니다. 미리보기는 숨김 방문 256회 후 정지하여 무한 순환을 알립니다. 이는 파일의 프레임 수 제한이 아닙니다.

브라우저의 타이머와 화면 갱신 빈도 때문에 모든 양의 지연 방문을 실제 화면에서 구분할 수 있는 것은 아닙니다. 특히 백그라운드 탭에서는 브라우저의 타이머 제한이 적용됩니다.

## 점프 대상 우선 캐시

캐시 예산의 기본값은 **32 MiB**이며 0·4·16·32·64 MiB로 바꿀 수 있습니다. 엔트리는 대상 프레임의 합성 완료 후·폐기 전 캔버스와, 필요한 경우 `PREVIOUS` 복원을 위한 캔버스를 함께 저장합니다. 두 배열의 실제 바이트 크기를 모두 예산에 포함합니다.

현재 합성 상태는 동작에 필수이므로 캐시와 별도로 유지합니다. 합성 캐시의 32 MiB는 프로세스 전체 메모리 한도가 아닙니다. 압축 해제한 마스크 배열에는 별도의 16 MiB LRU 캐시를 사용하고 그 사용량도 표시합니다. 마스크 배열 캐시는 HSV 변화량에 의존하지 않아 편집 후에도 재사용합니다. 한 배열이 이 예산보다 크면 임시로만 사용합니다. 입력 파일, 현재 상태, 압축 해제·합성 임시 버퍼, 출력 Canvas도 메모리를 사용합니다.

정적 이동 대상, 클립 시작점, 작은 랜덤 후보 집합에 가중치를 줍니다. 실제 이동 대상으로 선택된 프레임도 우선도를 높입니다. 큰 랜덤 구간 전체를 미리 생성하거나 영구 고정하지 않습니다. 반복해서 찾는 프레임은 적중 횟수로 추가 우대를 받습니다.

퇴출 점수는 다음과 같습니다. 점수가 가장 작은 엔트리부터 제거합니다.

```text
(1 + target_priority + log2(1 + hit_count)) / (1 + access_age)
```

`access_age`는 시간 대신 캐시 접근 순번의 차이입니다. 적중 횟수와 우선도에 상한을 두어 오래 사용하지 않은 대상이 계속 남지 않게 합니다. 프레임 0, 매 16번째 프레임, 우선 대상, 실제 요청 대상은 복원 중 저장 후보가 됩니다. 한 엔트리가 예산보다 크면 캐시에 넣지 않습니다. 캐시를 모두 비워도 이미지·시간·대상 선택 의미는 같습니다.

이 정책은 웹뷰어의 기본값입니다. 큰 리소스에서 측정한 결과에 따라 가중치와 중간 저장 간격을 바꿀 수 있으며 파일 포맷 변경은 필요하지 않습니다.

## 구현 위치

- [JSON5 파서](../../../packages/papng/src/json5.ts): 주석 지원, 중복 키 검증과 중첩 예산.
- [파서](../../../packages/papng/src/parser.ts): 컨테이너·CRC·확장 정보·메타데이터.
- [픽셀 복원](../../../packages/papng/src/pixels.ts): PNG 필터·Adam7·원본 RGB의 HSV 조절.
- [마스크 배열](../../../packages/papng/src/masks.ts): `paMD` 해석·압축 해제·참조 검증·공유 캐시.
- [재생기](../../../packages/papng/src/player.ts), [제어](../../../packages/papng/src/controls.ts), [난수](../../../packages/papng/src/random.ts): 방문·클립·프레임 제어와 정수 가중치 추출.
- [합성기](../../../packages/papng/src/compositor.ts), [캐시](../../../packages/papng/src/cache.ts): 표준 합성 상태와 바이트 예산.
- [Worker](src/worker.ts): 시간 예약, 작업 분할과 취소.
- [소켓](../../../packages/papng/src/sockets.ts): 메타데이터 검증과 프레임 번호 기반 조회.
- [부속 미리보기](src/attachment.ts): 별도 재생기, 로딩 취소와 pivot 연결.
- [평균색](src/mask-colors.ts): 원본 마스크 RGB의 알파 가중 평균과 표시용 이름.
- [UI](src/main.ts): 팔레트·샘플·재생 조작과 Canvas 출력.

난수는 `crypto.getRandomValues()`에서 얻습니다. 정수 누적 확률과 거부 추출을 사용하여 범위 나머지 연산의 편향을 피합니다. 큰 32비트 구간의 가중치 합은 `BigInt`로 계산하며 구간 전체를 배열로 만들지 않습니다. 시드 저장이나 재생 순서 재현 UI는 제공하지 않습니다.

## 지원 범위

현대적인 브라우저의 Worker·Canvas·`DecompressionStream`·`BigInt`가 필요합니다. 일반 PNG/APNG의 PAPNG 가져오기 변환, 파일 저장, 색 관리 프로파일 적용은 이 데모 범위에 포함되지 않습니다. `gAMA`·`cHRM`·`iCCP`가 있으면 색 관리 미적용을 알립니다. 애니메이션 밖의 기본 포스터는 재생 프레임에 포함하지 않습니다.

데모의 호스트 예산은 입력 파일 128 MiB, 캔버스 RGBA 한 장 128 MiB, 선택적 텍스트 메타데이터 8 MiB, JSON5 중첩 128단계 미만입니다. 넘으면 이유를 표시하여 중단하거나 선택적 메타데이터만 무시합니다. PAPNG의 크기·프레임 수 한도가 아닙니다. 잘못된 마스크는 원본 RGBA 유지, 잘못된 제어는 10ms 후 순차 진행으로 복구하고 경고합니다.

```sh
npm run samples
npm run check
npm run build
```

`npm run check`는 공개 소스의 TypeScript 타입을 검사합니다.

## GitHub Pages 배포

[공개 웹뷰어](https://tinywolf3.github.io/papng_format/)는 `main`에 push할 때 GitHub Actions에서 빌드·배포합니다. Actions의 **Deploy web viewer to Pages**를 수동 실행할 수도 있습니다. 수동 배포는 `main`에서만 실행됩니다.

저장소 Settings → Pages → Build and deployment → Source는 **GitHub Actions**로 설정합니다. 배포 설정은 [pages.yml](../../../.github/workflows/pages.yml)에 있으며 Node.js 24에서 `npm ci`와 `npm run build`를 실행합니다. `builds/web/viewer/`만 Pages에 업로드하므로 빌드 결과를 커밋할 필요가 없습니다. 샘플·Worker·웹 자산은 이 디렉터리에 함께 포함됩니다.

원본 명세는 Markdown으로 유지합니다. 선택한 로컬 파일은 브라우저에서 처리하며 업로드하지 않습니다.
